# Color Match Pond

Drag cute pond friends onto matching lily pads. Soft color matching for ages **4–6**.

**Play:** https://jmitchell238.github.io/color-match-pond/

Part of [Arcade Hub](https://jmitchell238.github.io/arcade-hub/).

## Modes

| Mode | Colors | Rounds |
|------|--------|--------|
| Free Play | 2 | Endless reshuffle |
| Easy | 3 | 5 |
| A Little More | 4 | 8 |
| Full Pond | 6 | 10 |

Wrong pad → gentle bounce home + hint (never a fail screen). Idle helper glows the right pad after a few seconds.

## Stack

Static HTML / CSS / Canvas PWA. No build step.

## Versioning

`GAME_VERSION` in `js/config.js` ↔ `CACHE` in `sw.js`.

## Local preview

```bash
python3 -m http.server 8080
```
